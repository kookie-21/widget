# Photo Share Widget App

A beautiful Android widget that allows you to share photos instantly with your connected partner.

## Features

- 📱 **Home Screen Widget** - View latest shared photos directly on home screen
- 🔄 **Real-time Sync** - Photos sync instantly via Firebase Firestore
- 👥 **Partner Connection** - Connect with friends using unique codes
- 🖼️ **Fullscreen View** - Tap photos to view them fullscreen
- 🎨 **Beautiful UI** - Modern, dark theme design
